# Instruction for AI

- After each task, create a git commit with proper message
- For react component, always use arrow function.
- Also for js or ts functions, use arrow function.
- use 'bun' as package manager

- always use best practices while making react components.
- try to break down the components into smaller components.
- use 'tailwindcss' for styling.
- while making UI, make it more fun and interactive. Consider user's experience and seamless features.
- follow pattern and conventions similar to other pages and components. Try to breakdown as much as possible following best practices.
